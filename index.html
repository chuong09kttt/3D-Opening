User Guide

🌟 Introduction

3D Opening Tool Pro is a design tool for creating and exporting MAC files for architectural openings. The application allows you to visualize 3D models and export files with precise technical specifications.

📐 1. Technical Specifications

📏
Dimension

Enter Length, Width, and Thickness in mm. The 3D model updates in real-time.

🔄
Orientation

Select the main axis: X, Y, or Z. The model rotates accordingly.

⭕
Corner Radius

Enter radius for each corner R1, R2, R3, R4. Default is 150mm. Each corner can have different values.

📍
Position

Set X, Y, Z coordinates to position the opening in 3D space. Default is 0.

🎤 2. Voice Control

Press 🎤 Voice and speak the following commands:

📐 "Length 2000, width 1500, thickness 300" → Update dimensions
📍 "Position x 100, y 200, z 50" → Update position
⭕ "Corner radius 200" → Update corner radius
🔄 "Orientation X" → Change axis orientation
📚 "Search living room window" → Search and open first document
📂 "Open document main door" → Open document from library
💾 "Save file" → Open export dialog
💡 Tip: The system automatically recognizes and updates parameters after you speak. You can speak multiple commands at once. Supports both English and Vietnamese.

📚 3. Document Library

➕
Add document

Enter Name, Drive Link, and Tags (comma separated) → Click "Add". Tags help with searching.

🔍
Search

Enter a query in the search box or use the Voice button to search by voice.

📂
Open document

Click Open next to a document or say "Open [document name]".

🗑️
Delete document

Click the delete button ✕ next to a document to remove it from the library.

💾 4. Export MAC File

🎤
Voice Auto Export

After speaking valid Length, Width and Thickness, the .mac file is automatically generated and downloaded once. No Export button is required.

💾
Manual Export

Click Export to name and download the .mac file.

🎤
Voice Export

Say "Save file" to trigger auto export.

⚠️ Important Notes

  • 📌 Library data is stored in Google Sheets (cloud).
  • 📌 Microphone permission is required for Voice features.
  • 📌 Exported files have .mac format.
  • 📌 Measurement unit is mm.
  • 📌 Supports both English and Vietnamese for Voice Commands.
