Hướng Dẫn Sử Dụng Chi Tiết

🌟 Giới Thiệu

3D Opening Tool Pro là công cụ hỗ trợ thiết kế và xuất file MAC cho các loại cửa, ô thoáng trong kiến trúc.

📐 1. Nhập Thông Số Kỹ Thuật

📏
Dimension

Nhập Length, Width, Thickness theo mm. Model 3D tự động cập nhật.

🔄
Orientation

Chọn trục X, Y hoặc Z cho Opening.

⭕
Corner Radius

Nhập bán kính bo góc R1-R4. Mặc định 150mm.

📍
Position

Thiết lập tọa độ X, Y, Z trong không gian 3D.

🎤 2. Điều Khiển Bằng Giọng Nói

📐 "Chiều dài 2000, chiều rộng 1500, chiều dày 300" → Cập nhật kích thước
📍 "Vị trí x 100, y 200, z 50" → Cập nhật vị trí
📚 "Tìm cửa sổ phòng khách" → Tìm kiếm trong thư viện
📂 "Mở tài liệu cửa chính" → Mở tài liệu từ thư viện
💾 "Lưu file" → Mở hộp thoại xuất file

📚 3. Quản Lý Thư Viện Tài Liệu

➕
Thêm tài liệu

Nhập Tên, Link Drive và Tags → Nhấn "Thêm".

🔍
Tìm kiếm

Nhập câu hỏi hoặc nhấn Voice để tìm bằng giọng nói.

📂
Mở tài liệu

Nhấn "Mở" hoặc nói "Mở [tên tài liệu]".

🗑️
Xóa tài liệu

Nhấn "✕" để xóa khỏi thư viện.

⚠️ Lưu Ý

  • 📌 Dữ liệu thư viện lưu trên localStorage. Xóa cache sẽ mất dữ liệu.
  • 📌 Cần cấp quyền Microphone để dùng Voice.
  • 📌 File xuất có định dạng .mac.
  • 📌 Đơn vị đo lường là mm.
